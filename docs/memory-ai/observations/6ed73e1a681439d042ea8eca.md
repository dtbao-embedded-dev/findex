## Finding

tauri-utils 2.10.1 config.rs emits copyright = None in the generated context, so app.config().bundle.copyright is always None at runtime. build.rs reads it from tauri.conf.json and passes FINDEX_COPYRIGHT via cargo:rustc-env.
