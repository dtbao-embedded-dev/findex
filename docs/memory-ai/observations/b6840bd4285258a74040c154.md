## Finding

Open with Claude used `cmd.exe /k claude` with the folder as working directory; cmd searches the working directory before PATH. Fixed in b036323 by running the full path from find_on_path and adding NoDefaultCurrentDirectoryInExePath=1 to the child env. Reproduced live with a marker-writing claude.cmd before and after. Windows Terminal strips nested quotes, so WT gets the path as one quoted argument.
