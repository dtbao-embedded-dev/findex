## Learned

cmd /k <name> searches the working directory before PATH, so running a tool by bare name inside an untrusted folder is a hijack; Windows Terminal re-parses and re-quotes its arguments, so nested cmd quoting breaks; a process created with Explorer as PROC_THREAD_ATTRIBUTE_PARENT_PROCESS takes Explorer's token; navigator.clipboard.writeText needs the window focused.
