## Request

On release/v0.1: add a splash (icon, version, copyright), a first-run drive picker, and fast optimized file/folder name search modelled on Eul45/omni-search; UI per the apple-design skill.

## Investigated

omni-search's C++ scanner (MFT via FSCTL_ENUM_USN_DATA, USN polling, naive single-threaded substring scan); tauri-utils codegen (drops bundle.copyright); tauri-build/embed_resource manifest linking (link-arg-bins).

## Learned

MFT read needs admin; release-only requireAdministrator manifest keeps dev and tests unelevated. A rayon walk on the shared pool starves searches. Saving under the volumes read lock queues installs and searches. Searches can reach Rust out of order.

## Completed

T1-T7 and four review-fix commits on release/v0.1 (f18fbc1..b80de4f): splash, drive setup, index store + parallel memmem query engine, MFT/walk/service + manifest, search screen, snapshots, USN watcher.

## Verification

Gates pass (vitest 39, cargo test 60, clippy -D warnings). Release perf: 1M-name query p95 15.3 ms; snapshot load 180 ms/1M. Runtime via screenshots and WebView2 DevTools on 6.28M real entries (unelevated walk). MFT, USN and release UAC paths NOT RUN: shell not elevated.

## Next Steps

Run mft_enumerates_system_volume and usn_sees_new_file in an Administrator terminal and launch the release build; then decide merge/push of release/v0.1.
